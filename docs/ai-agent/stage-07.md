# Stage 7 · VLA / 模仿学习（可选）

## 目标

在 Stage 6 已有安全基线和评测体系的前提下，探索学习型感知—动作策略。新增策略只负责适合学习的 Skill，并始终保留经典规划、人工接管和安全停止回退。

## 产出

- v2.0 VLA Skill（可选）。
- 数据集说明、训练配置、模型版本、评测报告和安全回退设计。

## 完成判据

- 学习型策略在预先定义的指标上优于或补足经典方案，而非只展示成功视频。
- 从数据到模型到部署结果可以复现，训练集与测试集没有泄漏。
- 不确定、越界、延迟过高或异常时能停止并回退。
- 跳过本 Stage 不影响 Stage 8 的通用 LLM 推理部署学习。
