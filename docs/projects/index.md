# Projects

这里收录能够说明问题定义、工程能力和结果质量的完整项目。

## 项目模板

每个项目至少回答：

- 问题与用户是谁？为什么值得解决？
- 为什么需要 Agent，而不是固定 workflow？
- 系统架构、数据流与安全边界是什么？
- 使用了哪些工具、模型、存储与部署组件？
- 如何评测成功率、延迟、成本与失败模式？
- 如何本地复现？有哪些截图、演示或在线 Demo？
- 做过哪些取舍？下一步怎么改？
